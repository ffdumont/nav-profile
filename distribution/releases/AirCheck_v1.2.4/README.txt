AirCheck v1.2.4 - Flight Profile and Airspace Analysis Tool

INSTALLATION:
1. Extract this folder to your desired location
2. Run AirCheck.exe to start the application

FIRST RUN:
- The application will create necessary folders automatically
- Import your AIXM file using the "Import AIXM" button
- Place your KML flight profiles in the data\samples folder

FOLDER STRUCTURE:
- data\input\     - Place AIXM XML files here
- data\samples\   - Place KML flight profiles here  
- data\output\    - Generated analysis files
- data\logs\      - Application log files
